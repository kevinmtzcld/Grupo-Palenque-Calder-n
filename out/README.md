# Archivos de Salida (`out/`)

Los archivos generados en esta carpeta corresponden a la compilación y ejecución del programa de prueba ubicado en [`tests/ejemplo.raz`](../tests/ejemplo.raz).

## Contenido

* **`compilador.exe`**: Ejecutable del compilador de **Razio**.
* **`tabla_simbolos.txt`**: Tabla de símbolos resultante del análisis léxico-sintáctico.
* **`tercetos.txt`**: Código intermedio en formato de tercetos.
* **`salida.asm`**: Código ensamblador x86 (NASM) generado por el compilador.
* **`salida.exe`**: Ejecutable final generado a partir de `salida.asm`.
